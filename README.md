# Ohm's Law and Power Calculator

## What it does
This calculator helps users find Voltage, Current, Resistance, or Power by entering the values they know. It also includes my own twist: a Power Safety Check that warns if power is too high, and a Calculation History that saves all results to view again.

## How to run it
Install Python 3, then run: python samuelgodwin_ohms_law_calculator.py
